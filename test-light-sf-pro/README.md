# 浅色背景 · SF Pro B 字体测试版

基于深色淡彩底测试版的 21 条无评级规则，仅调整颜色。SF Pro Text Bold 已转成 SVG 路径，保留原尺寸、1.4px 描边、6px 圆角。

- 字与描边使用深色，描边不透明。
- 同色淡底不透明度 8%。
- 保留蓝、青绿、紫、琥珀棕、焦橙、莓红、深绿与灰蓝的分类。
- 在 #FFFFFF、#F2F2F7、#E5E5EA 三种背景上计算文字与合成淡底的对比度，最低约 4.58:1；实际显示待实机确认。
- 当前版本为固定浅色配色，不自动切换主题。
